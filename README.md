# Divine carbon atom

Rotate a single three-dimensional structure to see **Aum**, the **traditional swastika**, and **alpha and omega** emerge from four dark-red ribbons. Each view uses the same ribbons on four tetrahedrally arranged surfaces. A separate **Quantum** view explores the electron probability density of carbon.

## Run it

Download [index.html](./index.html) and open the saved file in a browser with WebGL enabled. The file includes Three.js, OrbitControls, styles, source illustrations and the third-party license. It works offline. For static hosting, serve the repository root, with `index.html` as the entry point. There is no build step.

## Explore

| Control | Action |
| --- | --- |
| Drag | Rotate the model |
| Scroll or pinch | Zoom |
| Right-drag or Shift-drag | Pan |
| **1**, **2**, **3** | Select Aum, swastika, or alpha and omega |
| **Start the journey** | Tour the three perspectives |
| **Orbitals** | Reveal the translucent surfaces carrying the ribbons |
| **Fine-tune the view** | Adjust the roll and tour pace, or save a viewing angle in this browser |
| **↓** | Export the current canvas as a PNG |

## Reading the two views

**Symbols** reconstructs the geometry of the source illustrations. Rotating the tetrahedron changes the projected shape of the ribbons. Their paths and the scale of the surfaces are artistic choices.

**Quantum** samples the ground-state configuration of neutral carbon, **1s² 2s² 2p²**, using screened hydrogenic orbitals. Choose the total density or an individual orbital from the menu. The total uses a spherical average for the two 2p electrons. Each dot is a probability sample. The nucleus is enlarged for visibility. [NIST atomic data for carbon](https://physics.nist.gov/PhysRefData/Handbook/Tables/carbontable1.htm)
